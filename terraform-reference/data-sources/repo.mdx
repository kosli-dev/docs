Fetches one Kosli [repo](/tutorials/repositories), by its internal ID or by its name. Kosli records a repo when an attestation or trail references it. Use the returned `id` with the [`kosli_repo_tags` resource](/terraform-reference/resources/repo_tags) to tag the repo, or the [`kosli_repos` data source](/terraform-reference/data-sources/repos) to find several repos at once.

## Example usage

```terraform
terraform {
  required_providers {
    kosli = {
      source = "kosli-dev/kosli"
    }
  }
}

# Look a repo up by name. Set vcs_provider when the name exists on more than one provider.
data "kosli_repo" "api" {
  name         = "acme/platform/api"
  vcs_provider = "github"
}

# Look a repo up by its internal ID, shown by `kosli get repo`
data "kosli_repo" "by_id" {
  id = "6f1c2a9e-3b7d-4c55-9e0a-1d2f3b4c5d6e"
}

output "api_repo_id" {
  description = "Internal ID of the repo, for use with kosli_repo_tags"
  value       = data.kosli_repo.api.id
}

output "repo_name_for_id" {
  description = "Name of the repo with the given ID"
  value       = data.kosli_repo.by_id.name
}
```

## Schema

### Optional

- `id` (String) Internal Kosli ID of the repo. Set either `id` or `name`.
- `name` (String) Full name of the repo, including its namespace, for example `acme/platform/api`. Set either `id` or `name`. Names can repeat across VCS providers; set `vcs_provider` when more than one repo has this name.
- `vcs_provider` (String) VCS provider of the repo, for example `github` or `gitlab`. When set, narrows a lookup by `name`; conflicts with `id`. When not set, Kosli's value is returned, or null when Kosli could not determine it.

### Read-only

- `tags` (Map of String) Key-value pairs tagging the repo.
- `url` (String) URL of the repo.
- `vcs_instance` (String) VCS host of the repo. Null when Kosli could not determine it.
